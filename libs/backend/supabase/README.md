# backend-supabase

The Supabase implementation of the backend ports in `@aura/backend/api`, bound by `provideSupabaseBackend()`.
See "Supabase backend" in the repository README for running it locally.

- `supabase-clients.ts`: one client per club slug (sessions stored per club), one for the platform admin.
- `*.repository.ts`: the five ports. Club scoping is enforced by row-level security; queries also filter by club.
- `mapping.ts`: database rows to and from `@aura/shared/models`.
- `preview.ts`: the platform admin's preview uses the mock's in-memory sample data. This is the only place this
  library imports `@aura/backend/mock`.
- `database.types.ts`: generated by `npm run db:types`; do not edit.

Unit tests (`nx test backend-supabase`) cover the mapping. The repository tests run against a local Supabase and are
skipped unless `SUPABASE_URL` is set: `npm run test:supabase`.
